# 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 依赖安装失败 | 看首个错误和 Python 版本；当前锁定 Python 3.12。不能只看 installer returned a non-zero exit code |
| Coordinator is busy | 有活跃或残留协调器占用；正常结束会释放，过期租约在新提交时回收。不能凭此断言模型失败 |
| 页面超时，后台仍忙 | 同步协调器与页面等待预算不同，后台可能仍运行；勿重复触发昂贵计算 |
| 暂无实际淘汰赛赛程 | 检查 /api/v2/data/status 的主来源及 fallback、最后错误和阶段字段；不要用模拟结果填充 |
| API-Football 赛季权限错误 | 密钥有效与赛季可访问是两件事；确认套餐，再检查备用接口是否有可用字段 |
| LLM 解读降级 | 检查 LLM_API_KEY、BASE_URL、MODEL、网络和每日预算；成功缓存不会重复请求 |
| 修改 Secrets 后未生效 | 配置与模型在进程内缓存，按平台方式重启并检查；勿在公开日志打印密钥 |
| Render suspended | 平台暂停与应用异常不同；检查平台账单/用量，重新提交代码不一定恢复 |

## 已知尚未解决的问题
当前没有完整的前端协调器任务恢复/排队体验；占用槽与同步等待可能让用户看到忙状态。此次目录和文档整理不宣称解决这一问题。
LLM 提示词限制了事实范围，但没有完整数字与语义自动核验，仍可能误读晋级字段。模型数值以结构化卡片为准。

## 提交问题时提供
部署提交 SHA、平台、Python 版本、发生时间、按钮操作、脱敏错误和 run_id（如果存在）。不要附带 .env、Secrets、Authorization 头或数据库连接密码。
